本次更新适配 PRTS 新版 StoryPlayer 剧情模拟器。

### 新版播放器

- 支持角色与表情差分合成，以及手动、自动、快速播放。
- 同步缓存新版引擎模块、角色表、背景参数和音频变量，保留旧版剧情缓存兼容。
- 预下载使用新版引擎资源清单，补齐字体与界面纹理；离线重开不再依赖在线数据表。
- 在应用内使用 WebGL，解决播放中反复出现的 Pixi 纹理释放警告，并修复退出时重复销毁播放器的问题。

### 修复

- 修复确认弹窗提示 `dialog.confirm not allowed` 的问题。
- 删除缓存和批量下载会等待确认结果；取消或弹窗失败时不会执行操作。
- 完善新版缓存清理和启动失败处理。

### 升级说明

新版引擎采用不同的资源地址。升级后，请联网重新预下载需要离线观看的剧情；仅保留旧版媒体缓存不足以支持新版播放器离线演出。

Windows 桌面已实测确认弹窗、剧情连续播放、场景切换及退出；浏览器离线重开测试通过。Android、macOS、Linux 安装包由发布工作流构建，尚未逐平台实机验证。
